# Plano: Refatoração Visual Completa do EmpréstimosApp

## Objetivo
Aplicar o design system do shadcn/ui em todo o aplicativo, eliminando o visual "infantil" atual (sidebar azul escura com emoji, cards simples sem hierarquia visual) e adotando um tema claro profissional com cards, cores, tipografia e layout baseados nos blocks e templates oficiais do shadcn (especialmente `dashboard-01`).

## Decisões de Design (validadas com o usuário)
- **Escopo:** Todo o app (dashboard, sidebar, header, clientes, empréstimos, pagamentos, relatórios).
- **Alertas de atraso:** Cards destacados por cor (vermelho/laranja) por cliente em atraso, compactos.
- **Tema:** Claro profissional (sem dark mode obrigatório, mas manter suporte estrutural). Paleta: cinzas neutros, azul petróleo/escuro como primário, verde money para positivo, vermelho suave para alertas.

## Etapas de Implementação

### 1. Instalar componentes e dependências do shadcn
- `npx shadcn add card chart badge avatar separator dropdown-menu tabs select table skeleton`
- Verificar se `recharts` já está instalado (sim, está).
- Adicionar `@tabler/icons-react` se necessário para ícones consistentes com o dashboard-01 (ou manter `lucide-react` já usado).

### 2. Atualizar tema e tokens globais (`src/app/globals.css`)
- Ajustar `:root` para paleta profissional:
  - `--primary`: azul petróleo (oklch(~0.35 0.05 250))
  - `--chart-1` a `--chart-5`: tons de azul, verde, âmbar, vermelho, cinza para os gráficos
  - `--radius`: manter ~0.625rem ou aumentar para 0.75rem para cards mais suaves
  - `--sidebar`: fundo neutro claro (não azul escuro), com bordas sutis
- Manter `.dark` como está para compatibilidade futura.

### 3. Criar/Atualizar componentes de layout
- **`src/components/layout/app-sidebar.tsx`**: Nova sidebar baseada no padrão do shadcn (collapsible, offcanvas, com NavMain, NavUser). Fundo neutro, texto escuro, indicador de ativo com `bg-primary/10` + texto `primary`. Remover emoji 💰 e fundo `bg-slate-900`.
- **`src/components/layout/site-header.tsx`**: Header com breadcrumb/nav, avatar do usuário Clerk, título da página e ações contextuais.
- **`src/app/(dashboard)/layout.tsx`**: Adaptar para usar `SidebarProvider` + `SidebarInset` (padrão shadcn) ou manter estrutura flex simples mas com as novas peças.

### 4. Refatorar o Dashboard (`src/app/(dashboard)/page.tsx` + componentes)
- **KPI Cards (`kpi-cards.tsx`)**: Usar o padrão `SectionCards` do shadcn. Cada card com:
  - Ícone com fundo colorido suave (`bg-primary/10`, `bg-green-500/10`, `bg-red-500/10`, `bg-blue-500/10`)
  - Valor grande em negrito
  - Label secundária
  - Badge de tendência ou variação mensal (se possível calcular no server action)
- **Alertas de Atraso (`alertas-atraso.tsx`)**: Transformar de `Alert` em uma seção de cards horizontais/grade. Cada card mostra nome do cliente, valor em atraso, dias de atraso com badge de cor progressiva (amarelo 30-60d, laranja 60-90d, vermelho >90d). Usar `Card`, `Badge`, `Separator`.
- **Gráfico de Receita (`grafico-receita.tsx`)**: Migrar de `BarChart` básico para `ChartContainer` + `AreaChart` (ou manter `BarChart` mas usando `ChartContainer` do shadcn com `CartesianGrid vertical={false}`, tooltips customizados, config de cores via CSS vars). Adicionar `CardHeader` com descrição e footer com trend.
- **Pagamentos Recentes (`pagamentos-recentes.tsx`)**: Manter tabela simples mas estilizada dentro de `Card`. Adicionar `Badge` para tipo de pagamento (parcial/juros/quitação) com cores distintas.

### 5. Adaptar páginas restantes
- **`/clientes`**: Adicionar header com título + botão de ação. Tabela de clientes dentro de `Card`.
- **`/emprestimos`**: Header com título + botão. Tabela de empréstimos dentro de `Card`. Badge de status (ativo/quitado/inadimplente) com cores.
- **`/pagamentos`**: Mesmo padrão.
- **`/relatorios`**: Mesmo padrão.
- Reutilizar componente genérico de página (`PageHeader` + `PageContainer`) se necessário.

### 6. Melhorias de UX adicionais
- Adicionar `Skeleton` nos componentes clientes durante carregamento.
- Padronizar uso de `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter` em todas as seções.
- Garantir que o `ChartContainer` seja usado em todos os gráficos para acessibilidade e responsividade.

### 7. Validação
- `npx tsc --noEmit` para verificar tipos.
- `npm run build` para garantir que não há erros de build.
- Verificar responsividade mobile (sidebar Sheet, cards em grid 1-coluna).

## Riscos e Notas
- O shadcn `dashboard-01` usa `@tabler/icons-react`; o projeto atual usa `lucide-react`. Vamos manter `lucide-react` para não aumentar bundle, adaptando os ícones.
- A sidebar atual usa Clerk `signOut` e mobile Sheet. A nova sidebar deve preservar essa funcionalidade.
- O `ChartContainer` do shadcn requer que as cores sejam definidas como CSS vars (`--chart-1`, etc.); precisamos garantir que `globals.css` tenha esses tokens.
